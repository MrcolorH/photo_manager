01 / The Problem

按下快门之后，
才是真正「重」的环节。

摄影的乐趣在按下快门的那一刻，但随之而来的拷贝、整理、备份、删卡，往往要花掉一整晚。市场上主流后期软件都假设你「已经拷好了」——但拷文件这一步，正是最耗时的。

P · 01

系统复制没有进度反馈

Finder / 资源管理器只能干等，几百 GB 的 RAW 拷到一半不敢拔卡、又不敢中断，生怕丢数据。等待本身就是消耗。

P · 02

RAW 与 JPG 配对混乱

一组照片里一张 RAW + 一张 JPG 是常态。整理时删一张忘一张，久了仓库里堆满"孤儿 RAW"或"孤儿 JPG"，硬盘越用越满。

P · 03

多硬盘 / NAS 没有统一视图

主力盘、备份盘、NAS、外接 SSD 各自为政。想找一张去年拍的照片，得插上每块硬盘逐个翻。

P · 04

现有工具又贵又学不动

Lightroom、Capture One 一年动辄上千，主战场是调色，对「导入 + 整理」几乎没帮忙，新手得看一周教程才能上手。

02 / The Solution

拾光舱，把「拷贝 + 整理」
变成一次优雅的点击。

基于 Electron 打造的跨平台桌面应用（macOS / Windows），把摄影师最讨厌的「六步收尾流程」压缩为一键。开源、免费、专为影像设计。

01

存储卡一键入库

识别 SD / CF / XQD 卡自动挂载路径；带进度条、剩余时间预估、断点续传，再也不用提心吊胆地「干等 Finder」。

CRC 校验断点续传实时进度
02

RAW + JPG 智能配对

基于 EXIF 时间戳和文件名的双因子配对，让每一组「双胞胎」永远一起入仓、一起出仓。

EXIF 解析孤儿检测
03

多仓库统一管理

本地硬盘、外接 SSD、NAS 一键挂载为仓库，跨盘检索像在同一块盘里一样顺滑。

04

RAW 缩略图即时预览

无需 Lightroom 即可浏览 RAW 大图，自研解码器支持主流厂商（Canon、Nikon、Sony、Fuji）。

05

孤儿 RAW 一键清理

专治「删 JPG 留 RAW」或「删 RAW 留 JPG」导致的空间浪费，扫一遍即可找出并清理。

06

跨平台原生体验

基于 Electron 35 构建，在 macOS 与 Windows 上都拥有原生窗口、托盘、文件对话框体验，告别跨平台"塑料感"。

macOS 12+Windows 10+Apple Silicon
07

开源、免费、可扩展

完全开源的工作流引擎。后续可接入 AI 智能选片、云端备份、RAW 调色预设等增值能力，形成可持续的商业化路径。

router.post('/import', async (req, res) => {
  const { sourcePath, repoId } = req.body

  const files = await scanDir(sourcePath)
  const pairs = pairRawAndJpg(files)        // EXIF 配对
  const orphans = findOrphans(pairs)       // 孤儿检测

  await transfer(files, repoId, {
    onProgress: (p) => io.emit('progress', p),
    checksum: true,                       // CRC 校验
    resume: true                          // 断点续传
  })

  res.json({ success: true, pairs, orphans })

05 / The Impact

它对摄影师、
对行业意味着什么？

效率提升

把原本需要「插卡 → 复制 → 检查 → 整理 → 备份 → 删卡」六步手动操作压缩为一键完成。

  • 单次素材归整从 1 个通宵缩短到 1–2 小时
  • 释放出的时间直接转化为可承接的拍摄订单
  • 用开源免费方案替代每年上千元的订阅费
  • 跨平台一致体验，Mac 与 Windows 用户无缝迁移

商业价值

作为开源基础设施，拾光舱具备清晰的可持续商业化路径。

  • 云端备份增值服务（按容量订阅）
  • AI 智能选片（按次或订阅）
  • RAW 调色预设市场（创作者分成）
  • 面向摄影工作室的私有部署 / 团队协作版

社会价值

让影像管理不再是「专业人士的特权」。

  • 降低摄影学习门槛，让爱好者专注于创作本身
  • 开源生态鼓励高校、影像机构参与共建
  • 保护用户数据主权：素材始终在本地，不上传
  • 为残障 / 视障摄影教育提供可访问的工作流

未来路线

拾光舱不只是一个工具，更是摄影师工作流的中枢。
