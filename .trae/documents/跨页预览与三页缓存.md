# 跨页预览与三页缓存实现计划

## 问题分析

当前 [PhotoGallery.jsx](file:///Users/colorh/Project/Node后端/相机管理后台/frontend/src/pages/PhotoGallery.jsx) 使用 `<PhotoProvider>` + `<PhotoView>` 实现预览，`PhotoProvider` 仅包含当前页的 36 张照片。当用户浏览到第一页最后一张照片并点击"下一个"时，`react-photo-view` 会在当前页内循环，回到第一张，无法跨页。

## 解决方案

**核心思路**：放弃 `PhotoProvider` + `PhotoView` 组合方式，改用 `PhotoSlider`（`react-photo-view` 导出的底层组件），直接传入跨页合并的 `images` 数组，实现无缝跨页预览。

### 第二步：新增三页缓存管理函数

新增以下核心函数：

#### 2.1 `fetchPagePhotos(page)` — 获取指定页的照片数据

```jsx
const fetchPagePhotos = useCallback(async (page) => {
  if (!selectedRepo) return [];
  try {
    const res = await photoApi.getPhotos(category, {
      page,
      pageSize: pagination.pageSize,
      sortBy,
      sortOrder,
      repoId: selectedRepo
    });
    if (res.data.success) {
      return res.data.data.photos || [];
    }
  } catch (error) {
    console.error(`获取第${page}页照片失败:`, error);
  }
  return [];
}, [category, pagination.pageSize, sortBy, sortOrder, selectedRepo]);
```

#### 2.2 `loadPreviewPages(centerPage)` — 加载三页缓存

以 `centerPage` 为中心，加载 prev/current/next 三页数据：

```jsx
const loadPreviewPages = useCallback(async (centerPage) => {
  const totalPages = Math.ceil(pagination.total / pagination.pageSize);
  const pagesToFetch = [];

  if (centerPage > 1) pagesToFetch.push(centerPage - 1);
  pagesToFetch.push(centerPage);
  if (centerPage < totalPages) pagesToFetch.push(centerPage + 1);

  const results = await Promise.all(pagesToFetch.map(p => fetchPagePhotos(p)));
  
  let merged = [];
  pagesToFetch.forEach((page, i) => {
    const photosWithPage = results[i].map(photo => ({ ...photo, _page: page }));
    merged = merged.concat(photosWithPage);
  });

  setCachedPhotos(merged);
  cachedPagesRef.current = {
    min: pagesToFetch[0],
    max: pagesToFetch[pagesToFetch.length - 1]
  };

  return { merged, pagesToFetch };
}, [pagination.total, pagination.pageSize, fetchPagePhotos]);
```

#### 2.3 `preloadAdjacentPage(direction)` — 预加载/清除相邻页

当预览到达边界时，预加载下一页并清除远端缓存：

```jsx
const preloadAdjacentPage = useCallback(async (direction) => {
  const cached = cachedPagesRef.current;
  const totalPages = Math.ceil(pagination.total / pagination.pageSize);

  if (direction === 'next' && cached.max < totalPages) {
    const newPage = cached.max + 1;
    const photos = await fetchPagePhotos(newPage);
    const photosWithPage = photos.map(p => ({ ...p, _page: newPage }));

    setCachedPhotos(prev => {
      const updated = [...prev, ...photosWithPage];
      if (cached.min < cached.max) {
        return updated.filter(p => p._page >= cached.min + 1);
      }
      return updated;
    });
    cachedPagesRef.current = { min: cached.min + 1, max: newPage };
  }

  if (direction === 'prev' && cached.min > 1) {
    const newPage = cached.min - 1;
    const photos = await fetchPagePhotos(newPage);
    const photosWithPage = photos.map(p => ({ ...p, _page: newPage }));

    setCachedPhotos(prev => {
      const updated = [...photosWithPage, ...prev];
      if (cached.max > cached.min) {
        return updated.filter(p => p._page <= cached.max - 1);
      }
      return updated;
    });
    cachedPagesRef.current = { min: newPage, max: cached.max - 1 };
  }
}, [pagination.total, pagination.pageSize, fetchPagePhotos]);
```

### 第三步：改造预览切换逻辑

#### 3.1 打开预览 — 改造 `handlePreview` 中 JPG 分支

点击照片时，加载三页缓存并打开预览：

```jsx
const handlePreview = async (photo) => {
  if (category === 'video') {
    window.open(photo.url, '_blank');
  } else if (category === 'raw') {
    handleOpenLocation(photo, 'file');
  } else {
    // JPG预览 — 加载三页缓存
    const photoPage = photo._page || pagination.page;
    const { merged } = await loadPreviewPages(photoPage);
    
    // 找到该照片在合并列表中的索引
    const idx = merged.findIndex(p => p.id === photo.id);
    setPreviewIndex(idx >= 0 ? idx : 0);
    setPreviewVisible(true);
  }
};
```

#### 3.2 `onIndexChange` — 预览索引变化时触发跨页加载与分页同步

```jsx
const handlePreviewIndexChange = useCallback(async (index) => {
  setPreviewIndex(index);
  
  const currentPhoto = cachedPhotos[index];
  if (!currentPhoto) return;

  const currentPage = currentPhoto._page;
  const photoIndexOnPage = cachedPhotos
    .filter(p => p._page === currentPage)
    .findIndex(p => p.id === currentPhoto.id);
  const pageSize = pagination.pageSize;

  // 分页同步：外部分页器跳转到对应页面
  if (currentPage !== pagination.page) {
    setPagination(prev => ({ ...prev, page: currentPage }));
  }

  // 接近尾部 → 预加载下一页
  if (photoIndexOnPage >= pageSize - 3) {
    await preloadAdjacentPage('next');
  }
  // 接近头部 → 预加载上一页
  if (photoIndexOnPage <= 2) {
    await preloadAdjacentPage('prev');
  }
}, [cachedPhotos, pagination.page, pagination.pageSize, preloadAdjacentPage]);
```

## 关键设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 使用 `PhotoSlider` 而非 `PhotoProvider` | `PhotoSlider` | 可以直接传入动态 `images` 数组和 `index`，无需通过子组件注册 |
| 缓存策略 | 三页滑窗（prev/current/next） | 平衡内存与预加载开销，用户感知无延迟 |
| 预加载触发时机 | 到达当前页前3张或后3张时触发 | 确保用户翻到边界时下一页已缓存 |
| 跨页索引管理 | `_page` 字段标记照片所属页 | 便于反查当前预览照片的页码，同步分页器 |
| 分页同步方式 | 在 `onIndexChange` 中直接 `setPagination` | 保持分页器与预览位置实时一致 |

## 边界情况处理

1. **最后一页**：`cachedPagesRef.current.max >= totalPages` 时不触发 `preloadAdjacentPage('next')`
2. **第一页**：`cachedPagesRef.current.min <= 1` 时不触发 `preloadAdjacentPage('prev')`
3. **切换分类/排序/仓库**：`fetchPhotos` 会清空 `photos` 并重置分页，需同步清空 `cachedPhotos` 和 `cachedPagesRef`
4. **删除照片后**：`fetchPhotos` 刷新列表时同步刷新缓存
5. **单页数据**：总照片数 ≤ pageSize 时，不需要跨页逻辑，`PhotoSlider` 自然只包含一页数据
