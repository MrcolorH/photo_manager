- 自动检测项目位置

## 🎯 使用方法

### 方法一：启动台（最推荐 ⭐⭐⭐⭐⭐）
1. 按 F4 或点击 Dock 中的启动台图标
2. 找到 "启动相机管理后台" 或 "停止相机管理后台"
3. 点击即可

### 方法二：Dock 栏（快速访问 ⭐⭐⭐⭐）
1. 从启动台将应用拖到 Dock 栏
2. 以后直接点击 Dock 图标即可

### 方法三：应用程序文件夹
1. 打开 Finder
2. 前往 → 个人文件夹 → Applications
3. 双击相应的应用

### 方法四：项目目录
1. 打开项目文件夹
2. 双击 `.app` 或 `.command` 文件

## 🔧 技术细节

### 智能路径检测逻辑
```
1. 检查 .app 父目录是否有 start.sh/stop.sh
   ↓ 否
2. 检查硬编码的默认路径
   ↓ 否
3. 弹出对话框让用户选择项目文件夹
```

### 启动流程
```
1. 检测项目路径
2. 后台执行 start.sh（无终端窗口）
3. 等待服务启动（最多30秒）
4. 从日志中提取实际端口
5. 在默认浏览器中打开
6. 显示系统通知
```

## 💡 提示与技巧

### 添加到 Dock
1. 从启动台拖动应用到 Dock
2. 或者从 ~/Applications/ 拖动到 Dock
3. 右键点击 Dock 图标 → 选项 → 保持在程序坞中

### 查看日志
如果遇到问题，可以查看以下日志文件：
- 启动器日志：`/tmp/camera-launcher.log`
- 后端日志：`/tmp/backend.log`
- 前端日志：`/tmp/frontend.log`

### 修改项目路径
如果您移动了项目文件夹，应用会自动检测。如果检测失败：
1. 启动应用时会弹出文件夹选择对话框
2. 选择包含 `start.sh` 的项目根目录
3. 应用会记住选择（在本次会话中）

### 更改默认浏览器
应用会使用系统默认浏览器打开。要更改：
1. 系统偏好设置 → 通用
2. 修改 "默认 Web 浏览器"

## 📝 关于代码修改

**好消息：代码修改完全不影响启动！**

### 为什么？
启动应用的工作原理：
1. 启动应用本身只是一个"触发器"
2. 它执行的是项目根目录下的 `start.sh` 脚本
3. `start.sh` 会读取您最新的代码并启动服务

### 这意味着：
- ✅ 您可以随时修改前端/后端代码
- ✅ 修改后立即通过启动台启动，会使用最新代码
- ✅ 无需重新安装或更新启动应用
- ✅ 启动应用永远使用最新的 `start.sh` 脚本

### 只有以下情况需要重新安装：
- 移动了项目文件夹到完全不同的位置
- 删除了 `start.sh` 或 `stop.sh` 文件
- 想更换应用图标
