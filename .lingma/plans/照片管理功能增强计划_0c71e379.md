# 照片管理功能增强计划

## 需求分析

根据用户需求，需要实现以下5个功能：

1. **照片预览放大** - 不依赖浏览器缩放，提供独立的图片查看器
2. **照片预览旋转** - 支持图片旋转操作
3. **照片路径跳转** - 点击后能跳转到文件所在路径（提供多种访问方式）
4. **多选导出** - 支持多选照片并一键导出到指定目录
5. **存储卡导入路径选择** - 像仓库配置一样支持文件夹路径选择功能

## 技术选型

- **图片查看库**: react-photo-view (支持放大、旋转、拖拽等丰富交互)
- **路径跳转**: 后端提供API，前端调用系统命令打开文件夹或文件
- **多选导出**: 前端复选框多选 + 后端批量复制文件
- **路径选择**: 复用现有的文件夹选择功能

## 实施步骤

### 1. 安装依赖包

```bash
cd frontend
npm install react-photo-view
```

### 2. 修改 PhotoGallery.jsx 页面

#### 2.1 引入 react-photo-view
```jsx
import { PhotoProvider, PhotoView } from 'react-photo-view';
import 'react-photo-view/dist/react-photo-view.css';
```

#### 2.2 替换 Modal 预览为 PhotoView
- 移除现有的 Modal 预览组件
- 使用 PhotoProvider 包裹整个画廊
- 每个照片卡片使用 PhotoView 组件
- 配置旋转、缩放等工具栏

#### 2.3 添加多选功能
- 在状态中添加 `selectedPhotos` 数组
- 在每个照片卡片上添加复选框
- 添加全选/取消全选按钮
- 添加批量操作按钮区域

#### 2.4 添加路径跳转功能
- 在照片卡片操作区添加"打开位置"按钮
- 点击后弹出菜单选择：打开文件夹 / 在浏览器中打开
- 调用后端 API 执行相应操作

#### 2.5 添加批量导出功能
- 添加"导出选中照片"按钮
- 点击后弹出对话框选择目标目录
- 调用后端 API 批量复制文件

### 3. 后端新增 API 接口

#### 3.1 在 photoRoutes.js 中添加新路由

```javascript
// 打开文件所在文件夹
router.post('/open-location', async (req, res) => {
  const { filePath, mode = 'folder' } = req.body;
  // mode: 'folder' 打开文件夹, 'file' 打开文件
  // 根据操作系统执行相应命令
});

// 批量导出照片
router.post('/batch-export', async (req, res) => {
  const { fileIds, targetPath, repoId } = req.body;
  // 批量复制文件到目标目录
});
```

#### 3.2 实现 open-location 功能
- macOS: 使用 `open` 命令
- Windows: 使用 `explorer` 命令  
- Linux: 使用 `xdg-open` 命令

#### 3.3 实现 batch-export 功能
- 解码文件ID获取路径
- 确保目标目录存在
- 逐个复制文件（增量模式，不覆盖）
- 返回成功/失败统计

### 4. 修改 ImportPage.jsx 页面

#### 4.1 添加存储卡路径选择功能
- 在存储卡路径输入框旁边添加"选择文件夹"按钮
- 复用现有的文件夹选择逻辑（参考仓库配置的ha ndleRepoFolderSelect）
- 添加隐藏的 file input 元素
- 用户选择后自动填充路径到输入框

#### 4.2 优化用户体验
- 添加路径选择的提示信息
- 显示最近使用的路径历史（可选）
- 验证路径有效性

### 5. 更新 API 接口定义

在 `frontend/src/api/index.js` 中添加：

```javascript
export const photoApi = {
  // ... 现有接口
  
  // 打开文件位置
  openLocation: (filePath, mode) => api.post('/photos/open-location', { filePath, mode }),
  
  // 批量导出照片
  batchExport: (fileIds, targetPath, repoId) => 
    api.post('/photos/batch-export', { fileIds, targetPath, repoId })
};
```

### 6. 样式优化

- 调整 PhotoView 的工具栏样式，使其更美观
- 优化多选状态的视觉反馈
- 添加加载动画和进度提示
- 确保响应式布局正常工作

### 7. 测试要点

- 图片预览的放大、缩小、旋转功能
- 路径跳转在不同操作系统上的兼容性
- 多选导出的性能和错误处理
- 存储卡路径选择的便捷性
- 边界情况：文件不存在、权限问题、磁盘空间不足等

2. `frontend/src/pages/PhotoGallery.jsx` - 主要修改，添加预览、多选、导出功能
3. `backend/src/routes/photoRoutes.js` - 添加 open-location 和 batch-export 接口
4. `frontend/src/pages/ImportPage.jsx` - 添加存储卡路径选择功能
5. `frontend/src/api/index.js` - 添加新的 API 方法定义

## 注意事项

1. **安全性**: 路径跳转功能需要验证路径合法性，防止路径遍历攻击
2. **性能**: 批量导出大量文件时需要显示进度，避免界面卡顿
3. **兼容性**: 不同操作系统的命令不同，需要做平台判断
4. **用户体验**: 所有操作都需要有明确的反馈和错误提示
5. **增量导入**: 导出功能也应支持增量模式，不覆盖已存在的文件
