# 照片删除逻辑优化计划

## 需求分析

当前问题：
- 删除JPG照片时会自动同步删除对应的RAW文件
- 用户无法选择只删除JPG保留RAW
- 缺少批量删除功能

用户需求：
1. 默认删除JPG时不同步删除RAW
2. 提供选项让用户选择是否同时删除RAW
3. 支持批量删除选中的照片（带RAW删除选项）

## 实施方案

### 1. 修改前端 PhotoGallery.jsx

#### 1.1 修改单个删除函数 handleDelete
将当前的 Modal.confirm 改为自定义 Modal，添加复选框选项：

```jsx
const [deleteModalVisible, setDeleteModalVisible] = useState(false);
const [deletePhotoData, setDeletePhotoData] = useState(null);
const [syncDeleteRaw, setSyncDeleteRaw] = useState(false);

const handleDelete = (photo) => {
  setDeletePhotoData(photo);
  setSyncDeleteRaw(false); // 默认不勾选
  setDeleteModalVisible(true);
};

const confirmDelete = async () => {
  try {
    const res = await photoApi.deletePhoto(
      deletePhotoData.id, 
      syncDeleteRaw, // 传递用户选择的值
      selectedRepo
    );
    if (res.data.success) {
      message.success('删除成功');
      setDeleteModalVisible(false);
      fetchPhotos();
    }
  } catch (error) {
    message.error('删除失败');
  }
};
```

添加删除确认对话框：
```jsx
<Modal
  title="确认删除"
  open={deleteModalVisible}
  onOk={confirmDelete}
  onCancel={() => setDeleteModalVisible(false)}
  okText="删除"
  okType="danger"
  cancelText="取消"
>
  {deletePhotoData && (
    <div>
      <p>确定要删除照片 <strong>{deletePhotoData.name}</strong> 吗？</p>
      {category === 'jpg' && (
        <Checkbox 
          checked={syncDeleteRaw} 
          onChange={(e) => setSyncDeleteRaw(e.target.checked)}
          style={{ marginTop: 8 }}
        >
          同时删除对应的RAW底片
        </Checkbox>
      )}
    </div>
  )}
</Modal>
```

#### 1.2 添加批量删除功能
在批量操作栏添加"删除选中"按钮：

```jsx
<Button 
  danger
  icon={<DeleteOutlined />}
  onClick={handleBatchDelete}
  disabled={selectedPhotos.length === 0}
>
  删除选中 ({selectedPhotos.length})
</Button>
```

添加批量删除处理函数：
```jsx
const [batchDeleteModalVisible, setBatchDeleteModalVisible] = useState(false);
const [batchSyncDeleteRaw, setBatchSyncDeleteRaw] = useState(false);

const handleBatchDelete = () => {
  if (selectedPhotos.length === 0) {
    message.warning('请先选择要删除的照片');
    return;
  }
  setBatchSyncDeleteRaw(false);
  setBatchDeleteModalVisible(true);
};

const confirmBatchDelete = async () => {
  try {
    let successCount = 0;
    let failedCount = 0;
    
    for (const photoId of selectedPhotos) {
      try {
        const res = await photoApi.deletePhoto(photoId, batchSyncDeleteRaw, selectedRepo);
        if (res.data.success) {
          successCount++;
        } else {
          failedCount++;
        }
      } catch (error) {
        failedCount++;
      }
    }
    
    let msg = `删除完成！成功: ${successCount}`;
    if (failedCount > 0) msg += `, 失败: ${failedCount}`;
    if (batchSyncDeleteRaw) msg += '（已同步删除RAW）';
    
    message.success(msg);
    setBatchDeleteModalVisible(false);
    setSelectedPhotos([]);
    setSelectAll(false);
    fetchPhotos();
  } catch (error) {
    message.error('批量删除失败');
  }
};
```

添加批量删除确认对话框：
```jsx
<Modal
  title="批量删除确认"
  open={batchDeleteModalVisible}
  onOk={confirmBatchDelete}
  onCancel={() => setBatchDeleteModalVisible(false)}
  okText="删除"
  okType="danger"
  cancelText="取消"
>
  <div>
    <p>确定要删除选中的 <strong>{selectedPhotos.length}</strong> 张照片吗？</p>
    {category === 'jpg' && (
      <Checkbox 
        checked={batchSyncDeleteRaw} 
        onChange={(e) => setBatchSyncDeleteRaw(e.target.checked)}
        style={{ marginTop: 8 }}
      >
        同时删除对应的RAW底片
      </Checkbox>
    )}
    {batchSyncDeleteRaw && (
      <Alert
        message="警告"
        description="此操作将同时删除JPG和对应的RAW文件，且不可恢复！"
        type="warning"
        showIcon
        style={{ marginTop: 12 }}
      />
    )}
  </div>
</Modal>
```

### 2. 后端无需修改

后端的 `deletePhoto` 方法已经支持 `syncRaw` 参数：
- 文件：`backend/src/services/fileService.js`
- 方法：`async deletePhoto(photoId, options = {})`
- 参数：`options.syncRaw` 默认为 `true`，现在前端会传递 `false`

只需确保前端调用时正确传递参数即可。
